# Работа 3: QuickSort

- `QuickSort/Sort.h` — `algo::sort(first, last, comp)`: медиана из трёх, рекурсия только в меньшую часть, вставки на коротких интервалах, обмены через move.
- `QuickSort/main.cpp` — подбор порога сортировки вставками (запускать в Release).
- `QuickSort/Array.h` — динамический массив из работы 2, итератор дополнен операциями произвольного доступа (`--`, `+ n`, `- n`, `it - it`, `<`), поэтому `algo::sort(a.begin(), a.end(), comp)` работает (задание *).
- `QuickSortTests/SortTests.cpp` — 33 теста Google Test.

Для дешёвых в перемещении `int` оптимум ~32, для `std::string` — 10–16, а после 32 время растёт.
Выбран компромисс **16**. С ним `algo::sort` быстрее `std::sort` (MSVC): 201 мс против 236 мс на int и 57 мс против 72 мс на строках.

Глобальная `sort(T* first, T* last, Compare comp)` имеет ровно ту сигнатуру, что в задании, и вызывается без квалификации, как в примере. Она передаёт работу обобщённой `algo::sort`, которая принимает и итераторы `Array`.
